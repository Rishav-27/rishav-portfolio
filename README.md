## About this site

This repo is my personal portfolio — a single-page site that walks through who I am, what I've shipped, and what I'm building next.

I care about the second after the click: auth that doesn't fight you, search that stays instant on large catalogs, and interfaces that feel calm under load. I'd rather ship something boring that holds up than something clever that doesn't.

Built with **Next.js**, **TypeScript**, and a custom design system — no template, no dashboard aesthetic.
